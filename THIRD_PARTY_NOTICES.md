## Syntax highlighting (owner: highlight)

### GitHub Linguist — `data/github/linguist.json`

Language names, aliases, file extensions and `tm_scope`s compacted from
`lib/linguist/languages.yml` of [github-linguist/linguist](https://github.com/github-linguist/linguist)
(commit 5fbdfcb8133be2bed88bf3ce62b2335f50474525). The lookup order in
`src/render/highlight/pl/linguist.rs` (name / default alias / alias, comma split,
`FileBlob#extensions`) follows Linguist's `Language[]` and `find_by_extension`.

SPDX-License-Identifier: MIT — Copyright (c) 2017 GitHub, Inc.

### Primer GitHub syntax theme — PrettyLights scope map

The scope → `pl-*` class table in `src/render/highlight/pl/classes.rs` (`PRETTYLIGHTS_MAP`) is
`lib/github-light.map.json` of [primer/github-syntax-light](https://github.com/primer/github-syntax-light)
(generated by primer/github-syntax-theme-generator), "GitHub Light v0.5.0".

SPDX-License-Identifier: MIT — Copyright (c) 2012 - 2017 GitHub, Inc.

### Linguist grammars ported for GitHub output

`src/render/highlight/pl/session.rs` ports the two rules of the `text.shell-session` grammar of
[atom/language-shellscript](https://github.com/atom/language-shellscript)
(SPDX-License-Identifier: MIT — Copyright (c) 2014 GitHub Inc.);
`src/render/highlight/pl/diff.rs` ports the line rules of the `source.diff` grammar of
[textmate/diff.tmbundle](https://github.com/textmate/diff.tmbundle) (TextMate bundle license:
"Permission to copy, use, modify, sell and distribute this software is granted. This software is
provided "as is" without express or implied warranty, and with no claim as to its suitability
for any purpose.").

### Rouge 5.1.0 — `data/gitlab/rouge-registry.json` and Rouge-derived tables

`data/gitlab/rouge-registry.json` is `Rouge::Lexer.registry` (lexer tags and aliases) plus each
lexer's title and `*.ext` filename globs, extracted from [rouge-ruby/rouge](https://github.com/rouge-ruby/rouge)
5.1.0. `src/render/highlight/rouge/diff.rs` and `rouge/console.rs` port the `Diff` and
`ConsoleLexer` lexers; `rouge/words.rs` copies the keyword/builtin word tables of the `Rust`,
`Python`, `Javascript`, `Typescript`, `C`, `Cpp`, `Go`, `Java` and `Shell` lexers; the class
names are Rouge's token short names (`lib/rouge/token.rb`). The scope → class rules in
`rouge/classes.rs` (`BASELINE_RULES`) are md-render's own (`.dev/research/gitlab/tools/scope_map.py`).

SPDX-License-Identifier: MIT — Copyright (c) 2012 Jeanine Adkisson.

## GitLab: gitlab-glfm-markdown formatter, Banzai filters, emoji data (render-gitlab)

Used in: `src/render/gitlab/**`, `data/gitlab/emoji.json`.

* `src/render/gitlab/formatter.rs` and `src/render/gitlab/glfm.rs` are ports (kept nearly
  verbatim) of `src/formatter.rs` and `src/glfm.rs` of the
  [gitlab-glfm-markdown](https://gitlab.com/gitlab-org/ruby/gems/gitlab-glfm-markdown) gem,
  version 0.0.43.
* The other files of `src/render/gitlab/` re-implement, filter by filter, GitLab's Banzai
  pipeline (`lib/banzai/filter/*.rb`, `lib/gitlab/front_matter.rb`, `lib/banzai/color_parser.rb`,
  `lib/rouge/formatters/html_gitlab.rb`, gitlab-org/gitlab @ `8396d286bea7`, content outside
  `doc/`, `ee/` and `jh/`, i.e. MIT Expat) and embed its constants (sanitizer allowlists, regular
  expressions, message strings).
* `data/gitlab/emoji.json` is a compacted copy of GitLab's emoji database
  (`https://gitlab.com/-/emojis/4/emojis.json`, generated from the
  [tanuki_emoji](https://gitlab.com/gitlab-org/ruby/gems/tanuki_emoji) gem, MIT,
  Copyright (c) 2021 GitLab B.V.; its emoji names and descriptions derive from gemojione (MIT,
  Copyright (c) 2013 Jonathan Wiesel), emojione-alpha-codes (MIT) and Unicode's emoji data
  files) and of `fixtures/emojis/aliases.json` of gitlab-org/gitlab (MIT Expat).

### two-face / bat syntax definitions (embedded via the `two-face` crate)

The syntax set used by the tokenizer is `two_face::syntax::extra_newlines()` of the
[two-face](https://codeberg.org/CosmicHarper/two-face) crate (SPDX-License-Identifier:
MIT OR Apache-2.0 — Copyright (c) 2023-2025 The `two-face` developers), which bundles the syntax
definitions of [bat](https://github.com/sharkdp/bat) (MIT OR Apache-2.0 — Copyright (c) 2018-2023
bat-developers). Each bundled syntax definition keeps its own license; the full list with
license texts is two-face's `generated/acknowledgements_full.md` (also available
programmatically through two-face's optional `acknowledgement` feature).


The sanitizer in `src/render/gitlab/sanitize.rs` also reproduces the default configuration and
the element-cleaning rules of [Sanitize](https://github.com/rgrove/sanitize) 7.0.0 (MIT,
Copyright (c) Ryan Grove) and the `ALLOWLIST` of
[html-pipeline](https://github.com/gjtorikian/html-pipeline) 2.14.3 (MIT, Copyright (c) 2012
GitHub Inc. and Jerry Cheung); both are under the MIT license text above (with their own
copyright lines).
